# sideporch.app

The first, deliberately plain Sideporch website: static HTML and CSS, no build
step. Vercel serves this directory (project root directory `website`) at
<https://sideporch.app>. The logo, fonts and screenshots are copies from
`assets/` and `docs/screenshots/`; copy them again when those change.

Preview locally with any static server, for example `python3 -m http.server -d website`.
