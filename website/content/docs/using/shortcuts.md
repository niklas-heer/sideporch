| Keys | What they do |
| --- | --- |
| <kbd>⌘</kbd> <kbd>K</kbd> (<kbd>Ctrl</kbd> <kbd>K</kbd>) | Jump to a channel, person or page |
| <kbd>Alt</kbd> <kbd>↑</kbd> / <kbd>↓</kbd> | Previous or next channel |
| <kbd>Alt</kbd> <kbd>Shift</kbd> <kbd>↑</kbd> / <kbd>↓</kbd> | Previous or next unread channel |
| <kbd>↑</kbd> | Edit your last message, in an empty message box |
| <kbd>Enter</kbd> / <kbd>Shift</kbd> <kbd>Enter</kbd> | Send / new line |
| <kbd>Esc</kbd> | Close the thread |
| <kbd>⌘</kbd> <kbd>/</kbd> (<kbd>Ctrl</kbd> <kbd>/</kbd>) | Show all shortcuts |

In an empty message box, typing `/` suggests commands; <kbd>↑</kbd> <kbd>↓</kbd> choose one, and <kbd>Tab</kbd> or <kbd>Enter</kbd> takes it. `/help` lists them all.
