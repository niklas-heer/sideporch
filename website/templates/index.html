Why run your own chat?

Team chat has become something you rent: per person, per month, with your history held by someone else. Sideporch is for the teams, clubs, families and communities who would rather own theirs.

No bill per person

Sideporch is free and open source under the MIT license. Invite fifty people or five thousand; the cost is the small server it runs on.

Your history stays yours

No message limits and no history that disappears after 90 days. Everything lives in one directory on your server, and a backup is one file you can download.

Nothing else to run

One program, no database server, no mail server, no containers to wire together. Updates are signed, and Sideporch can install them for you.

Familiar from minute one

Channels, threads, mentions, reactions and search work the way people know from Slack. It installs on phones like an app, with notifications.

Everything people expect from team chat, and nothing to rent

Talk the way you're used to

  • Channels, threads and direct messages, with mentions, reactions, pins and saved messages.
  • Polls where people pick one, pick several, or rank the options to find what most can live with.
  • Search with from:, in:, has:file and dates, that fixes typos from your own words.
  • Read aloud and dictate in 31 languages, with voices that run on your server.
  • Reminders, scheduled messages, link previews, GIFs, Markdown and diagrams.
  • Statistics: messages per day, the busiest channels, and who writes most, from public channels only.
  • Connect with other Sideporch servers to share channels and write to people there, like Slack Connect.

Simple to run yourself

  • One program, one folder. No database server, no mail server, nothing else to install.
  • Signed updates, installed for you. Admins hear about new releases, security fixes first, and Sideporch can install them itself. Your data moves along, and a copy is kept first.
  • Backups from the browser or on a schedule; restoring is one command.
  • Bring your Slack history: channels, threads and reactions come along.
  • Webhooks and Lua automations for monitors, CI and bots; Slack-style webhooks work unchanged. Share automations with other servers as a file.

Ready for a public community

  • Open sign-up, or requests a moderator approves, with rules people agree to.
  • Trust levels: newcomers earn uploads, links and more by taking part.
  • Roles and permissions, like moderators or who may upload files.
  • Passkeys, authenticator apps and email sign-in links, and a policy that requires them.
  • Reports and time-outs so moderators can act quickly.

A small server is plenty

In load tests, everyone was online at once and posted every two minutes; a message only counted if it reached everyone within a second. Plan with a quarter of this on slower real servers: a Raspberry Pi still serves a thousand people.

Set it up in three steps

  1. Install it

    On a server, use the install script: it checks the download and puts one file in place. Every release has static binaries for Linux and macOS, on x86-64 and ARM.

    Script for servers
    curl -fsSL https://raw.githubusercontent.com/niklas-heer/sideporch/main/install.sh | sh
    Docker
    docker run -d -p 8080:8080 -v sideporch:/data ghcr.io/niklas-heer/sideporch
    Homebrew
    brew install niklas-heer/tap/sideporch
    Nix
    nix run github:niklas-heer/sideporch

  2. Open it and become the admin

    The first person to open it creates the admin account. Put it behind HTTPS with Caddy or your usual proxy so phones get notifications and passkeys work. How to run it on a server

  3. Bring people in

    Share invite links, or open sign-up for a community. Nobody needs an email address unless you want sign-in links.

Curious how it works? Under the hood explains the design with diagrams. The documentation covers the rest: updates, backups, moving from Slack and automations. Sideporch is young; expect rough edges before 1.0, and read the release notes for what changed.

Questions people ask

Is Sideporch really free?

Yes. It's open source under the MIT license, with no paid edition and no limits on people or messages. You pay for the server it runs on, which can be a small VPS, a home server or a Raspberry Pi.

Who is it for?

Teams that want Slack's way of working without the per-person bill, clubs and families who want a private place to talk, and public communities that need sign-up, trust levels and moderation. What Sideporch is

What do I need to run it?

A machine with Linux or macOS, or anything that runs Docker, and a domain name for HTTPS, which phones need for notifications and passkeys. Half a CPU and 512 MB serve thousands of people. Run it on a server

Can we move over from Slack?

Yes. Import a Slack export with channels, threads, direct messages and reactions, and keep using the webhooks your tools already send. Move from Slack

Does it work on phones?

Yes. Sideporch installs from the browser like an app on iPhone and Android, with push notifications sent straight from your server. Phones and notifications

Is my data private?

It stays on your server. Sideporch has no analytics and doesn't phone home; it asks GitHub for new releases, which you can switch off, and fetches link previews and GIFs only if you let it. Security

Is it ready for us?

Sideporch is young. It works end to end and is tested thoroughly, but expect rough edges and breaking changes before 1.0. Keep backups, and read the release notes before updating.

How do we leave, if we want to?

Everything is in one data directory, and the database is plain SQLite that any tool can read. A backup is one archive you can download from the browser. Backups
